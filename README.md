# Drift Hall

A walkable hall of your own photos. The pictures stay on your computer.

## Start it with one double-click

1. Download this project.
   - On the project page, click the green **Code** button, then **Download ZIP**.
   - Unzip it. You will get a folder. Leave that folder where you can find it.
2. Install Node.js once, if you do not already have it.
   - Open [https://nodejs.org](https://nodejs.org).
   - Download the version marked **LTS** and run the installer. The usual choices are fine.
3. In the unzipped folder, double-click:
   - **Windows:** `Start Drift Hall.bat`
   - **Mac:** `Start Drift Hall.command`
   - **Linux:** `Start Drift Hall.sh`
4. Your browser opens the hall. The first time, it may sit for a minute while it finishes setting up. Leave the black window open.
5. Click **Open folder** and choose the folder that has your pictures.

Next time you double-click the starter, that same folder opens on its own.

You can also drag a photo folder onto the starter icon.

If a Mac says it cannot open the file, right-click it, choose **Open**, then **Open** again.

Close the black window when you are finished. That turns the hall off.

The website version still works in a browser. There you can open a folder or drop photos on the page. On your own computer the starter is the fast way: it reads the folder directly, so a large set does not have to be copied in first.

## Walking around

- **W A S D** or the arrow keys move. A steps left, D steps right.
- Drag to look. Double-click to capture the mouse. **Q** and **R** turn. **Shift** moves faster.
- In the flying rooms, **Space** rises and **C** drops.
- Keys **1** through **6** change the room. **E** goes to the picture under the crosshair. **F** stars it.
- Stars, tags, and notes stay in the browser. **Save into folder** writes a small `DriftHall/marks.json` file beside the pictures. The pictures themselves are never changed.
